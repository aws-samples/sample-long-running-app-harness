   - AttachmentSchema: extends with id, s3Key, uploaderId, timestamps
   - AttachmentUploadResponseSchema: attachment + uploadUrl

2. **CDK Infrastructure** (`infrastructure/lib/canopy-stack.ts`):
   - Added S3 bucket `canopy-attachments-v2-{account}-{region}` for file storage
   - Enabled CORS on bucket for browser uploads
   - Granted Lambda S3 read/write permissions
   - Added ATTACHMENT_BUCKET_NAME environment variable to Lambda
   - Added AttachmentsBucketName stack output
   - CDK tests updated: 20 tests passing (was 16)

3. **Backend handlers** (`backend/src/handlers/attachments.ts`):
   - POST /issues/:id/attachments - creates attachment metadata + returns pre-signed S3 upload URL
   - GET /issues/:id/attachments - lists all attachments for an issue
   - GET /attachments/:id/download - returns pre-signed S3 download URL
   - DELETE /attachments/:id - deletes from S3 and DynamoDB
   - DynamoDB keys: PK=ATTACHMENT#{id}, SK=METADATA, GSI1PK=ISSUE#{issueId}

4. **Frontend UI** (`frontend/src/components/IssueDetailPanel.tsx`):
