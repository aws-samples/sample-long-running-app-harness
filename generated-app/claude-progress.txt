CANOPY PROJECT MANAGEMENT APP - Progress Summary
==================================================

## Architecture
- Monorepo with npm workspaces: shared/, backend/, frontend/, infrastructure/
- Backend: AWS Lambda + DynamoDB (single-table) + API Gateway HTTP API
- Frontend: React + React Router + React Query + Tailwind CSS v4 + DnD Kit + Recharts
- Infrastructure: AWS CDK (TypeScript)
