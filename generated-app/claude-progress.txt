CANOPY PROJECT MANAGEMENT APP - Progress Summary
==================================================

## Architecture
- Monorepo with npm workspaces: shared/, backend/, frontend/, infrastructure/
- Backend: AWS Lambda + DynamoDB (single-table) + API Gateway HTTP API
- Frontend: React + React Router + React Query + Tailwind CSS v4 + DnD Kit + Recharts
- Infrastructure: AWS CDK (TypeScript)

## Deployed Resources
- API URL: https://q4rf5i4bal.execute-api.us-east-1.amazonaws.com
- DynamoDB Table: canopy-main-table (deployed from earlier deployment, API uses TABLE_NAME env var)
- Lambda: canopy-api-handler
- S3 + CloudFront for frontend hosting

## Frontend Features
- Dashboard with project cards, stats, staggered animations
- Kanban board with 4 columns (To Do, In Progress, In Review, Done) and DnD Kit drag-and-drop
- Backlog view with sprint sections and issue rows
- Sprint creation and management
- Reports view with Recharts pie charts and bar charts
- Settings view with project name/description/color editing and delete functionality
- Roadmap view with epics empty state
- Create Issue modal with type, priority, summary, description, story points
- Search modal (Cmd+K)
- Issue detail panel (slide-in from right) with status buttons, priority dropdown, comments
- Sidebar navigation with project-specific items, collapse/expand
- Project selector dropdown in header
- Keyboard shortcuts: Cmd+K (search), Cmd+[ (sidebar toggle), C (create issue), Escape (close)
- Forest canopy color palette with Space Grotesk headers + DM Sans body
