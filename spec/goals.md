# Goals

## What
A tiny static status dashboard: a single static page showing
- a title
- the current UTC build time, baked in at build step
- a green "all systems go" badge

## For whom
Test project for the repo owner; validates the build/deploy pipeline more than serving end users.

## Scope
- Single page, plain HTML/CSS/JS, no frameworks
- Lives entirely inside `status-page/` within an existing repo
